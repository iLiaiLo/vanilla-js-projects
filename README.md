# 🎨 Vanilla JS Mini-Projects Collection

Welcome to my collection of frontend mini-projects built entirely using **Vanilla JavaScript, HTML5, and CSS3**. 

Every project in this repository is completely lightweight and zero-dependency. There is **no installation, no `npm install`, and no build steps required**. You can run any project instantly by simply opening its `index.html` file directly in your web browser!

---

## 🚀 Projects Overview

### 1. Drawing App (`/drawing-app`)
A smooth, interactive canvas sketching tool.
* **Features:** Custom brush thickness adjusting sliders, real-time value tracking, and clean drawing mechanics.
* **How to run:** Open index.html in your browser.

### 2. CSS Tool Generators (`/css-generators`)
A suite of tools designed to help web developers experiment with styles and instantly grab the generated code.

* **RGB-Hex-HSL Converter (`/css-generators/rgb-hex-hsl`):** An interactive color playground that visually converts colors across different color spaces in real time.
* **CSS Filter Generator (`/css-generators/css-filter-generator`):** Apply visual filters (blur, brightness, contrast, saturation) to images via sliders and copy the generated CSS code instantly.
* **How to run:** Open index.html in your browser.

### 3. Clocks (`/clocks`)
Two distinct approaches to rendering real-time tracking on the DOM.

* **Analog Clock (`/clocks/analog-clock`):** A classic clock face rendering rotating hour, minute, and second hands synced to your local machine's system time.
* **Digital Clock (`/clocks/digital-clock`):** A clean, modern digital readout featuring a ticking 24-hour display format.
* **How to run:** Open index.html in your browser.
